# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short:
- Be respectful and inclusive.
- Assume good intent.
- Focus on what is best for the community, and especially for the people who rely on accessible software.

Report unacceptable behaviour to the maintainers privately through the contact options on the maintainer's GitHub profile. All reports are handled confidentially.
